Everything in this folder

  • results/: executed notebook, CSV tables, run metadata, log, completion marker, HTML report, comparison chart, four comparison PNGs, four modality PNGs and four animated slice GIFs.
  • notebooks/: clean inference notebook and Kaggle metadata for rerunning.
  • weights/: both pretrained binaries and provenance, with verified SHA-256 hashes.
  • reproducibility/: notebook/PDF builders, verification helpers and upstream source snapshot. Training code is reference material and was not executed for these results.
  • MANIFEST_SHA256.csv: integrity hashes for package files, excluding the manifest itself. BUILD_INFO.json: version, source and scope record.

How to use it

  1. Read the teacher report and open the visual results.
  2. Use the presentation notes for the demonstration; the saved results work offline.
  3. To rerun, import the clean notebook into Kaggle, attach BraTS-Africa and the checkpoint input, select GPU, and follow the technical reference.

Raw MRI scans are not included; they remain on Kaggle. No credentials are included. The notebook is public. Access to the separate weights input may depend on the account; both checkpoint files are also included locally. Do not change relative paths if you want the offline figures to remain linked.
